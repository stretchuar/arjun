# Arjun 2.0

Offline SLI capture for iPad. This repository is a static site: serve these files over HTTPS (GitHub Pages), open the address in Safari, and use Share > Add to Home Screen. After one online open from the Home Screen icon, the app runs fully offline.

Data stays on the device. To update, change `index.html`, bump `VERSION` in `sw.js`, and open the app once while online.
